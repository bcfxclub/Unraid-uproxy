出口模式

在 Unraid 上拉起一个 WARP 容器作为免费出口。免费、无限流量，但出口 IP 是共享的，GitHub / Docker Hub 偶有限流。

「接入点 IP」用于绕开被污染的 DNS：部分网络把 WARP 接入点域名解析到黑洞 IP，此时预检会给出可达 IP，填进去即可。

快速开始 出口怎么选 下发流程 常见问题

快速开始

把本目录放到 Unraid 的 /mnt/user/appdata/uproxy，终端执行：

bash install.sh

完成后会打印访问地址和口令，形如 http://<Unraid-IP>:8765/?token=xxxx，点开即用。Unraid 默认没有 docker compose，脚本用的是原生 docker build + docker run，无需额外装插件。

出口怎么选

docker pull：优先走 registry-mirrors（「下发」页勾选 mirror，零成本、不依赖代理）。代理兜底。

CA 商店 / GitHub / 插件更新：这些小流量才挂代理。手动填已有代理地址，或贴订阅链接让 sing-box 起一个节点。

WARP：免费的 Cloudflare 出口，先点「启动前预检」——它会检测你那条线路能不能连上 WARP 接入点。国内很多线路被污染，连不上就别指望。

下发流程

「下发」页勾选目标 → 先点「生成变更预览」核对 diff → 确认无误再点「应用变更」。每个目标写前自动备份，可在「备份与还原」页回滚。CA 商店改完需重启整机或 emhttp 才生效，工具不会自动重启。

常见问题

CA 里的 Docker 图标不显示：那是你自己的浏览器直连 GitHub，不经过 Unraid，无解。

docker build 报 lookup …: no such host：daemon.json 里的镜像源域名失效了，跑 bash fix-mirror.sh 自动体检重写。

页面能打开但点什么都是「未授权」：把口令填到左侧底部输入框，或直接用带 ?token= 的完整地址打开。
